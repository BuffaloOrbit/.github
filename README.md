# Buffalo Orbit organization profile

This public repository hosts the [Buffalo Orbit GitHub profile](https://github.com/BuffaloOrbit).

- [`profile/README.md`](profile/README.md) is the organization-facing introduction, product showcase and English/Vietnamese overview.
- [`assets/products/`](assets/products/) contains the four application icons and product images.
- [`assets/showcase/`](assets/showcase/) contains the company website preview, mobile image, animated GIF and full MP4 recording.
- `assets/icon.png` and `assets/banner.png` are the existing Buffalo Orbit brand illustrations.

## Updating the showcase

Keep image and video URLs pointed at this public `.github` repository so visitors can see the assets without access to private product repositories. The profile uses absolute URLs because it is rendered on the organization page as well as inside this repository.

When updating a product, keep its icon, description, feature list and caption aligned. Preserve the distinction between actual app captures, example design output and workflow illustrations. Product availability and public links should reflect published releases.
