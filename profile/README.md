### Buffalo Agents

**One workspace. Many paths forward.**

Bring projects, worktrees and coding-agent sessions into one workspace. Terminal, editor, tasks and testing tools stay close to the work.

- **Separate worktree contexts:** each branch has its own working context, with agent sessions running in parallel.
- **Multiple providers:** work with several coding-agent providers inside the same workspace.
- **Persistent sessions:** a session daemon keeps work going while you are away.
- **App control and verification:** agents can drive and test a running app as part of the development flow.

`Workspace → Worktree → Agent session`

### Buffalo Design

**Give ideas form. Give design structure.**

A shared design document for people and agents, combining an editable canvas, structured layers and reusable design values.

- **Structured canvas:** build and edit visual layouts with a clear document hierarchy.
- **Layers:** keep individual elements organized and directly editable.
- **Design tokens:** share visual values across the document.
- **Agent tools:** let agents edit the same canvas you work on.

`Canvas → Layers → Tokens`

### Buffalo Proxy

**Pause the request. Understand the flow.**

Inspect and shape HTTP/HTTPS traffic in a native interface, from an individual request to the response that follows it.

- **Traffic capture:** inspect recorded requests and responses, statuses and timing details.
- **Breakpoints:** pause requests to inspect or modify them before continuing.
- **Mapping and rewrite:** apply rules to traffic instead of repeating manual changes.
- **MCP integration:** allow agents to read and control the tool within their workflow.

`Capture → Breakpoint → Response`

### Buffalo Cleaner

**See your storage. Clean with intent.**

Understand what takes up space, scan by data group and review items before choosing what to clean.

- **Smart Scan:** summarize storage usage across data groups.
- **Developer Junk:** find leftovers from development tools.
- **Review before cleanup:** inspect individual items before cleaning.
- **Clean History:** review what was cleaned afterward.

`Scan → Group → Review`

## Four directions, one engineering baseline

Our products grow out of four areas of work:

| Direction | What we build | The flow |
| --- | --- | --- |
| **Software production automation** | Agent workflows, generators, templates and repeatable release tooling. | Intent → build → review → release |
| **Social content** | Systems for creating, scheduling and distributing content. | Idea → create → schedule → publish |
| **Multimedia apps** | Tools for creating, processing and understanding images, audio and video. | Capture → process → deliver |
| **Games** | Interactive systems, content pipelines and player experiences. | Systems → content → build → ship |

**Anything done by hand twice is a signal to think about a tool for the third time.**

### How we build

- **Understand the problem:** make the user's workflow and expected result clear before choosing a tool.
- **Make repeated work reproducible:** turn recurring steps into scripts, templates and systems.
- **Keep the standard transferable:** use review, documentation and training to carry it to the next person.
- **Verify and keep going:** build the process that lets a product evolve after its first launch.

## Tiếng Việt

**Buffalo Orbit là studio xây dựng sản phẩm và hệ thống tự động hóa để ý tưởng không dừng lại ở bản thử nghiệm.** Ba founder, bốn hướng phát triển và một tiêu chuẩn chung: rõ ràng, có thể kiểm chứng, có thể lặp lại.

<details>
<summary><strong>Khám phá đầy đủ bốn sản phẩm</strong></summary>

### Buffalo Agents — Không gian làm việc cho coding agent

Quản lý project, worktree và nhiều phiên agent trong một workspace. Mỗi worktree có ngữ cảnh riêng; hỗ trợ nhiều provider, session daemon và công cụ điều khiển/kiểm tra app đang chạy. Terminal, editor và task nằm trong cùng luồng làm việc.

### Buffalo Design — Canvas cho người và agent

Thiết kế trên một tài liệu có cấu trúc: canvas chỉnh sửa trực tiếp, layers rõ ràng và design tokens dùng chung. Người dùng và agent cùng làm việc trên một canvas. Ảnh giới thiệu là sản phẩm thiết kế mẫu tạo bằng công cụ.

### Buffalo Proxy — Quan sát và điều chỉnh HTTP/HTTPS

Ghi nhận request/response, xem status và timing, đặt breakpoint để kiểm tra hoặc sửa request trước khi tiếp tục. Mapping, rewrite và MCP giúp kết nối công cụ với luồng làm việc của agent.

### Buffalo Cleaner — Hiểu dung lượng trước khi dọn

Smart Scan tổng hợp dữ liệu theo nhóm; Developer Junk tập hợp phần dư từ công cụ lập trình. Xem lại từng mục trước khi dọn và theo dõi kết quả qua Clean History. Ảnh giới thiệu là kết quả quét thực tế trước khi dọn.

Website giới thiệu có **tiếng Việt và tiếng Anh**, animation Rive riêng cho từng sản phẩm, Three.js ở hero, chuyển cảnh theo cuộn và hỗ trợ giảm chuyển động. Ảnh Agents, Proxy và Cleaner là ảnh chụp app thực tế; animation là minh họa tính năng.
